# Abraham Peyret — Índice de universos

Página de entrada para la presencia digital de Abraham Peyret. Presenta los universos **Living Contract** y **Diseño de Autor** en una experiencia web editorial.

## Estado

Proyecto web estático conservado como una versión funcional del índice de marca.

## Tecnología

- HTML
- CSS
- JavaScript
- Recursos visuales locales y externos

## Uso

Abre `index.html` en un navegador. No requiere proceso de compilación.
